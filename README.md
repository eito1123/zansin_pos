# zansin学祭POS

共通パスワードでのログイン、端末名登録、自動バックアップ、交換端末への復元に対応しています。初回のクラウド設定は [supabase/README.md](supabase/README.md) を参照してください。未設定・未ログイン・通信断でも通常の会計は利用できます。

iPad横画面向け、外部依存のない静的Webアプリです。初期価格は1セット300円。数量（1〜999セット）・預かり金額・価格は画面のテンキーで入力します。

## 起動

Node.js環境で `npm start` を実行して http://localhost:4173 を開きます。`npm test` で会計ロジックと認証APIのテストを実行できます。会計は静的Webアプリで完結し、クラウド機能だけがVercel FunctionsとSupabaseを使用します。ログイン用CookieはHTTPS専用のため、本番またはHTTPSのテスト環境で接続確認してください。

## iPadへの設置

index.html、style.css、app.js、logic.js、db.js、cloud.js、sw.js、manifest.webmanifest、icon.svgを同じHTTPS静的ホスティングへ配置し、Safariで開きます。「オフライン利用可能」の表示を待ち、共有メニューからホーム画面へ追加してください。初回読み込みには通信が必要です。LAN内HTTPのプレビューはService Workerが動作しないため、iPadでのオフライン試験にはHTTPSが必要です。

売上は利用中のブラウザ・オリジンのIndexedDBに保存します。プライベートブラウズは避け、会期中は同じURLと同じブラウザ/PWAで使ってください。端末のストレージ削除やOSのデータ退避などによる消失に備え、履歴からCSV/JSONを定期的に保存してください。出力は全期間・取消済みを含み、CSV日時はUTC（Z付き）です。画面日時・本日集計は端末の現地時刻です。

## 動作確認

- 3セットをタップ（会計へ直接遷移） → 3000入力 → お釣り2100円 → 会計完了 → 履歴に900円。
- 会計完了ボタンは1つ。預かり未入力なら計算をスキップして確定し、入力済みで不足している間は完了不可。Cでクリアすると未入力に戻ります。
- 5セット以上は数量テンキーで入力して「お会計へ」。戻ると数量を保持します。
- 価格を350円に変更 → 次の3セットは1050円、過去の会計は900円のまま。
- 取消確認でキャンセル → 変化なし。取消実行 → 履歴に残り、本日集計から除外。
- リロード・ブラウザ/PWA終了後に履歴と価格が維持されること。
- 「オフライン利用可能」表示後、機内モードで再起動し会計・履歴・出力を確認。
- 保存失敗時は入力を保持し、未完了のエラーを表示。保存中は操作をロック。

## Vercelでの公開・更新

vercel.jsonで静的サイトとして構成済みです。ビルドは `node build.mjs`、公開ディレクトリは `dist` です。公開用ファイルのみをコピーし、内容が変わるとService Workerのキャッシュバージョンも自動更新します。

初回はVercelへのログインとプロジェクト作成が必要です。CLIを利用する場合はプロジェクト直下で `vercel --prod` を実行します。以後も同じプロジェクトへデプロイし、iPadでは固定の本番URLを使用してください。デプロイごとに発行される個別URLは保存領域が別になるため、日常の会計には使わないでください。

更新後は通信可能な状態でアプリを開いてください。新しい版を取得すると画面下部に「最新版に更新」が表示されます。会計を完了し、数量未入力の画面で押すと更新します。別タブから更新された場合も、会計中の画面は保持し、会計完了後の数量未入力画面で再読み込みします。旧版に更新ボタンがない場合は、一度オンラインで開いて読み込みを待ち、POSのタブ/PWAをすべて閉じて開き直してください。SafariのWebサイトデータを削除すると売上も消えるため、更新のために削除しないでください。売上はまずiPad内に保存します。バックアップを有効にした場合のみ、Vercelの認証APIを経由してSupabaseに送信します。テスト売上は履歴から取り消して集計から除外できます。

## PDF出力

履歴の「PDF出力」から全期間の明細を表示し、「PDF保存 / 印刷」でブラウザの印刷画面を開きます。iPadでは印刷プレビューの共有操作からPDFをファイルに保存してください。取消済みも明細に残し、合計から除外します。通信不要です。
