# 炭と、祭。 学祭焼き鳥POS

iPad横画面向け、外部依存のない静的Webアプリです。初期価格は1セット300円。数量（1〜999セット）・預かり金額・価格は画面のテンキーで入力します。

## 起動

Node.js環境で `npm start` を実行して http://localhost:4173 を開きます。`npm test` で会計ロジックを検証できます。server.mjsは開発プレビュー専用で、実運用にバックエンドは不要です。

## iPadへの設置

index.html、style.css、app.js、logic.js、db.js、sw.js、manifest.webmanifest、icon.svgを同じHTTPS静的ホスティングへ配置し、Safariで開きます。「オフライン利用可能」の表示を待ち、共有メニューからホーム画面へ追加してください。初回読み込みには通信が必要です。LAN内HTTPのプレビューはService Workerが動作しないため、iPadでのオフライン試験にはHTTPSが必要です。

売上は利用中のブラウザ・オリジンのIndexedDBに保存します。プライベートブラウズは避け、会期中は同じURLと同じブラウザ/PWAで使ってください。端末のストレージ削除やOSのデータ退避などによる消失に備え、履歴からCSV/JSONを定期的に保存してください。出力は全期間・取消済みを含み、CSV日時はUTC（Z付き）です。画面日時・本日集計は端末の現地時刻です。

## 動作確認

- 3セットをタップ（会計へ直接遷移） → 3000入力 → お釣り2100円 → 会計完了 → 履歴に900円。
- 会計完了ボタンは1つ。預かり未入力なら計算をスキップして確定し、入力済みで不足している間は完了不可。Cでクリアすると未入力に戻ります。
- 5セット以上は数量テンキーで入力して「お会計へ」。戻ると数量を保持します。
- 価格を350円に変更 → 次の3セットは1050円、過去の会計は900円のまま。
- 取消確認でキャンセル → 変化なし。取消実行 → 履歴に残り、本日集計から除外。
- リロード・ブラウザ/PWA終了後に履歴と価格が維持されること。
- 「オフライン利用可能」表示後、機内モードで再起動し会計・履歴・出力を確認。
- 保存失敗時は入力を保持し、未完了のエラーを表示。保存中は操作をロック。

## Vercelでの公開・更新

vercel.jsonで静的サイトとして構成済みです。ビルドは `node build.mjs`、公開ディレクトリは `dist` です。公開用ファイルのみをコピーし、内容が変わるとService Workerのキャッシュバージョンも自動更新します。

初回はVercelへのログインとプロジェクト作成が必要です。CLIを利用する場合はプロジェクト直下で `vercel --prod` を実行します。以後も同じプロジェクトへデプロイし、iPadでは固定の本番URLを使用してください。デプロイごとに発行される個別URLは保存領域が別になるため、日常の会計には使わないでください。

更新後は通信可能な状態でアプリを開き、読み込みを待ってからPOSのタブ/PWAをすべて閉じて開き直してください。更新は既存画面を閉じた後に適用され、会計中の強制更新は行いません。売上は引き続きiPad内に保存し、Vercelには送信しません。テスト売上は履歴から取り消して集計から除外できます。
